# DigitalWeightBalancerAPI (ASP.NET Core)

## Run
1. Install .NET SDK (7.0 or 8.0).
2. From `DigitalWeightBalancerAPI` folder run:
   `dotnet restore`
   `dotnet run`
3. Open Swagger: https://localhost:5001/swagger (or http://localhost:5000/swagger)

This project uses an in-memory EF Core database seeded with a sample user:
username: admin, password: 1234
